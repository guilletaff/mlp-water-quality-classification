Water Quality and Potability Classification using MLPThis repository contains a Deep Learning project focused on analyzing the physicochemical attributes of water samples to classify them as potable (1) or non-potable (0). Utilizing a Multi-Layer Perceptron (MLP) neural network, the project achieves robust predictive performance by implementing non-linear feature selection and strict validation pipelines.  📂 Project StructureMLP_WaterQuality.ipynb: The main Jupyter notebook detailing the data exploration, preprocessing, feature engineering, and neural network training pipeline.  Redes Neuronales. Water Quality and Potability .pdf: The academic project report comprehensively explaining the theory, materials, methodology, and conclusions.  water_potability.csv: The raw dataset containing 3,276 water quality records across 10 distinct chemical and physical attributes.  water_preprocessed.csv: The optimized dataset generated after cleaning, imputing, scaling, and filtering for the top 7 non-linear features.  🛠️ Data Preprocessing & Feature EngineeringTo guarantee optimal convergence and maximum accuracy for the neural network, the data undergoes a rigorous preprocessing sequence:  Duplicate Removal: Eliminating identical rows to prevent repetition bias.  KNN Imputation: Replaced missing values in critical variables (ph, Sulfate, and Trihalomethanes) using a KNNImputer with 5 neighbors to preserve data integrity.  MinMax Scaling: Standardized all features into a uniform scale between 0 and 1 to balance gradient weights during training:
  $$X_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}$$Feature Selection: Rather than using linear methods like ANOVA, Mutual Information (MI) scoring was deployed to isolate non-linear patterns. The dataset was filtered down to the top 7 features:  Hardness  Sulfate  Conductivity  pH  Organic Carbon  Turbidity  Solids  🧠 Model Architecture & TrainingThe core classifier is an advanced Artificial Neural Network structured to prevent over/underfitting while maximizing non-linear learning capabilities:  Network Structure: An inverted pyramid Multi-Layer Perceptron (MLP) consisting of three hidden layers: 128 ➔ 64 ➔ 32 neurons.  Activation & Optimization: Hidden layers leverage ReLU (max(0, x)) to catch complex, non-linear chemical interactions, while utilizing the adaptive Adam optimizer.  Regularization & Validation:Early Stopping with a 10% validation split prevents the model from memorizing noise.  A rigorous 10-Fold Cross-Validation (K-Fold) ensures the metrics are robust and entirely free from data-partition bias.  📊 Key ResultsAverage Global Accuracy: 78.91%  ROC AUC Score: 0.8365 (demonstrating strong statistical capability in separating potable vs. non-potable classes)  Balanced Class Metrics:  Non-Potable (0): 81% Precision / 76% Recall  Potable (1): 77% Precision / 82% Recall  💻 Requirements & DependenciesTo run the notebook, ensure you have the following Python libraries installed:  Bashpip install numpy pandas matplotlib seaborn scikit-learn tensorflow keras plotly
